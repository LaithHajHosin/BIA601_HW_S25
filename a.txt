Project Overview: Genetic Algorithm Product Recommender System
Core Application
You built a Product Recommender System using Genetic Algorithms that:

Reads user data, product data, ratings, and behavior from CSV files

Creates a SQLite database (projject_database.db) with tables for users, products, ratings, and user_behavior

Uses a genetic algorithm (population size 50, 30 generations) to generate personalized product recommendations

Calculates recommendation scores based on category matching, price tier, ratings, popularity, seasonality, and margin

Outputs recommendations to a JSON file (src/recommendations.json)

Key Files Created
Database population script - Reads CSVs and creates SQLite database with calculated fields (age_group, region, customer_segment, price_tier, seasonality, etc.)

ProductRecommenderGA class - Main recommendation engine with methods:

get_user_embedding() - Creates user preference profile

get_product_features() - Extracts product attributes

calculate_product_score() - Scores individual products

recommend_products() - Runs GA to generate recommendations

save_recommendations_to_json() - Exports results to JSON

Flask Web API (app.py) - Turns the recommender into a web service with endpoints:

/run-recommender/<user_id> - Triggers GA and updates JSON

/recommendations - Returns current JSON file

/health - API status check

Problems Encountered & Solved
GitHub blocking database files - Solved by using CSV files as source of truth and generating database locally

GitHub blocking .sql files - Even empty ones were blocked; solution was to use alternative extensions (.txt) or generate directly from Python

Virtual environment activation - Provided commands for Windows (.venv\Scripts\activate) and Mac/Linux (source .venv/bin/activate)

"Not enough values to unpack (expected 3, got 2)" - Error in unpacking return values from recommend_products() method

Current Status
You have a working genetic algorithm recommender system that can be run as a local API server on http://localhost:5000, which generates personalized product recommendations when you visit URLs like http://localhost:5000/run-recommender/3.
